# Smirty8181

Desktop и web-приложения на Rust, TypeScript, JavaScript и C#.

## Из проектов

### [Universal Device Manager](https://github.com/Smirty8181/universal-device-manager)

Менеджер периферии для Windows: обход HID-устройств, заряд, RGB-пресеты, макросы, ремап клавиш и каталог драйверов.

**Rust · Tauri 2 · Vue 3 · SQLite**

### [Bot-watch2gether](https://github.com/Smirty8181/Bot-watch2gether)

Telegram Mini App для совместного просмотра видео: комнаты, синхронный плеер, чат и координация в реальном времени.

**React · Vite · Node.js · Express · Socket.IO**

### [NoKeybord-mod](https://github.com/Smirty8181/NoKeybord-mod)

Клиентский Fabric-мод Minecraft: голосовые команды распознаются локально через whisper.cpp.

**Java · Fabric · whisper.cpp**

### [Focus Keeper](https://github.com/Smirty8181/focus-keeper)

Утилита для локального кооператива: удерживает несколько окон «в фокусе» одновременно.

**Python · ctypes · WinAPI**
